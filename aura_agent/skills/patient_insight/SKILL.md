# Patient monthly recap — v4

Application assessment mode uses the bounded-headline contract: read all retained
findings and write one short, gentle descriptive sentence with exact supporting
fact IDs. The server owns the two-item default card selection and inspectable
remaining changes. Do not rewrite those cards. No numbers, dates, causes or
technical baseline vocabulary are needed. If wording fails verification, the
record recap remains visible. This does not authorize an interruption.

Read the selected record and draft at most two short, gentle descriptive
sentences for the default patient-home recap. Use everyday words: "your usual",
"sleep time", "recent data". Never say baseline, drift or anchor. Use the person's own reference, never a
population normal range. Cite the recorded facts; preserve uncertainty and
re-establishing reference trust.

Prefer distinct recorded signal/source changes, not two repetitions of the same
sleep change. When a channel has multiple retained intervals, describe its latest
recorded interval; do not rank severity or erase earlier clinician history.
Prefer descriptive wording instead of extra arithmetic. When mentioning dates, copy
the exact ISO YYYY-MM-DD string from a cited fact. Do not convert sleep minutes into
clock times, convert units, round numbers, calculate differences or add new numerics.
Do not reassure about safety or mental state,
create tasks, scores, guilt or reminders. If no retained change is recorded,
return no claims and no question IDs. This is a recap, not an interruption.

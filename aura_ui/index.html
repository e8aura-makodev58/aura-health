            Honest about its limits

            Your context. Your choice.

            A research-informed prototype

            For adults aged 25–60 on stable, clinician-managed antidepressant maintenance treatment. AURA organizes information; it does not replace a clinician.

            AI wording and synthetic data

            Only synthetic fixtures are used here; no real wearable API is connected. For future institutional use, AURA is intended to connect to an institution-managed on-premises or private-cloud model, subject to review—not a validated deployment capability.

            Synthetic fixtures demonstrate engineering behavior, not clinical efficacy. Safety resources and wording need review before real use.

            Missing data is just missing data

            Wearable availability and trust in a baseline are separate. There is currently no governed automatic exit from “Re-establishing”.

            This is not a secure clinical system

            There is no production patient authentication or automatic clinician sharing. Use synthetic data only.
